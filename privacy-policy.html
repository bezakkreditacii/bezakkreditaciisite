Политика обработки персональных данных

Дата публикации: 22 августа 2026 года

Настоящая Политика обработки персональных данных определяет порядок обработки и защиты персональных данных пользователей сайта-портфолио bezakkreditacii (далее — «Сайт»).

1. Оператор персональных данных

Оператором персональных данных является:

Роберт (bezakkreditacii)

Контакт для связи: через контактные данные и ссылки на социальные сети, размещённые на Сайте.

2. Общие положения

Настоящая Политика разработана в соответствии с законодательством Российской Федерации в области персональных данных.

Оператор уважает право пользователей на неприкосновенность частной жизни и принимает необходимые меры для защиты персональных данных.

3. Какие персональные данные обрабатываются

Сайт не содержит форм регистрации, личных кабинетов, форм обратной связи, подписок на рассылки или иных инструментов, посредством которых пользователь непосредственно передаёт Оператору свои персональные данные.

Оператор не осуществляет целенаправленный сбор через Сайт таких данных, как:

  • фамилия, имя и отчество;
  • номер телефона;
  • адрес электронной почты;
  • адрес проживания;
  • паспортные данные;
  • платёжные данные;
  • данные для создания учётной записи.

4. Использование файлов cookie

Сайт не использует собственные системы аналитики, рекламные трекеры или иные инструменты, предназначенные для целенаправленного отслеживания поведения пользователей.

При этом отдельные технические файлы cookie и иные технические данные могут обрабатываться используемыми сервисами и инфраструктурой, необходимыми для функционирования и безопасности сайта.

Такая обработка осуществляется соответствующими поставщиками сервисов в соответствии с их собственными правилами и политиками обработки данных.

5. Ссылки на сторонние ресурсы

На Сайте могут размещаться ссылки на сторонние интернет-ресурсы, включая Telegram, Instagram и YouTube.

Переход пользователя по такой ссылке осуществляется добровольно. После перехода обработка персональных данных осуществляется соответствующим сторонним сервисом в соответствии с его собственной политикой конфиденциальности.

Оператор Сайта не контролирует порядок обработки персональных данных сторонними ресурсами.

6. Цели обработки персональных данных

Поскольку Сайт не содержит форм сбора персональных данных и систем регистрации пользователей, Оператор не осуществляет целенаправленную обработку персональных данных пользователей для регистрации, заключения договоров, рассылок или рекламных кампаний посредством Сайта.

7. Защита персональных данных

Оператор принимает разумные организационные и технические меры для предотвращения неправомерного доступа, изменения, раскрытия или уничтожения персональных данных, которые могут обрабатываться в связи с функционированием Сайта.

8. Права пользователей

Пользователь имеет права, предусмотренные законодательством Российской Федерации в области персональных данных.

При наличии вопросов относительно обработки персональных данных пользователь может обратиться к Оператору по контактам, указанным на Сайте.

9. Изменение Политики

Оператор вправе изменять настоящую Политику при изменении законодательства Российской Федерации, функциональности Сайта или порядка обработки данных.

Актуальная версия Политики размещается на данной странице.
